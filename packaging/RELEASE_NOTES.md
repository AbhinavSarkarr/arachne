A living spider colony on your desktop. Download **one** installer for your system:

| System | Download | Install |
|---|---|---|
| **Windows 10/11** | `Arachne-Windows-Setup.exe` | Run it. If SmartScreen says *unknown publisher*: **More info → Run anyway**. No admin needed. |
| **macOS** (Apple Silicon) | `Arachne-macOS.pkg` | Right-click the file → **Open** → **Open** (the app isn't notarised yet). |
| **Linux** (Ubuntu / Debian) | `Arachne-Linux.deb` | `sudo apt install ./Arachne-Linux.deb` |

After installing you don't need to open anything:

- **Ctrl+Shift+B** — release the spiders (resumes your saved colony)
- **Ctrl+Shift+B** again — save and put them away
- **Ctrl+Shift+F** — drop a fly at your cursor
- Tray icon → **Colony Journal** (log, population, family tree, ★ favourites, Spider-dex),
  **photo**, **10-second clip**, **sound**, real clock / real calendar (Linux: also Ctrl+Shift+J)

The colony keeps living between sessions: webs, families, seasons and all.
